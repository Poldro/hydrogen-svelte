# hydrogen-svelte

> **Unofficial.** Not affiliated with, endorsed by, or supported by Shopify.

Svelte 5 bindings for [Shopify Hydrogen](https://github.com/Shopify/hydrogen) 2026.10, the
framework-agnostic storefront toolkit. The API mirrors `@shopify/hydrogen/vue`, adapted to
Svelte 5 idioms: runes, context and `{@attach}`.

Work in progress. See [`docs/NOTES.md`](docs/NOTES.md) for the design notes.

## Layout

- `packages/hydrogen-svelte`: the library
- `apps/example`: a SvelteKit storefront using it
